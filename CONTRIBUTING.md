# Contributing

Thanks for your interest in agent-visitor-center-webmcp. Contributions of every size are welcome: issues, docs, schemas for new sites, tests and code.

## Getting started

1. Look for issues labeled `good first issue` or `help wanted`, or open an issue describing what you'd like to change.
2. Fork the repo and create a branch from `main`.
3. Keep each pull request to one change, with tests where the change has behavior.
4. Describe what changed, why, and how you tested it in the pull request.

## Sites and content

A demo schema for a site you don't run must only read public content at runtime and must not copy the site's text, logos or icons into this repo. Check the site's terms first and link them in the pull request.

## Developer Certificate of Origin

Sign off every commit (`git commit -s`) to certify you wrote the change or have the right to submit it under the project's license, per the [Developer Certificate of Origin](https://developercertificate.org/).

## Conduct

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
