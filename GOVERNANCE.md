# Governance

## Roles

- **Maintainers** review and merge pull requests, cut releases and set the roadmap. Current maintainer: Dakota Fabro ([@dakotafabro](https://github.com/dakotafabro)).
- **Contributors** are anyone who opens an issue, reviews a pull request or submits a change.

## Decisions

Decisions are made in public, on issues and pull requests. Maintainers aim for consensus; when it isn't reached, the maintainers decide by majority, and with one maintainer, that maintainer decides and records the reasoning on the issue.

## Becoming a maintainer

A contributor with a record of merged, reviewed work can be nominated by any maintainer on a public issue. They become a maintainer when the existing maintainers agree. The goal is maintainers from more than one organization.

## Changes to this document

Changes to governance go through a pull request open for at least one week.
