# Security Policy

## Reporting a vulnerability

Please report security issues privately through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on this repository, not in a public issue.

Include what you found, how to reproduce it and what it affects. You'll get a reply within seven days.

## Scope

Tools registered through this kit run in a visitor's browser with the page's permissions. Reports about a tool doing more than its schema describes, or about a schema that lets a page or agent act beyond what the site intended, are in scope.

## Supported versions

Only the latest release gets security fixes until the project reaches 1.0.
